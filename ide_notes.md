# Git в VS Code

## Что удобно делать в VS Code

1. Просматривать изменения файлов через визуальный diff.
2. Видеть список изменённых файлов в Source Control.
3. Просматривать историю изменений и авторов строк с помощью GitLens.

## Что удобнее делать в терминале

Сложные операции с ветками и историей Git удобнее выполнять через терминал, потому что команды и их результат полностью видны и контролируются пользователем.
