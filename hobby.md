# Мой пет-проект

Идея: HomeParty — приложение для организации домашних мероприятий. Пользователь может создавать события, указывать участников, бюджет и планируемые расходы.

Стек: Python

Цель: научиться разрабатывать приложение для планирования мероприятий и применять Git для контроля версий проекта.
